Enrutamiento Client-Side

Esta aplicación funciona 100% en el navegador mediante el parámetro ?p= en la URL:

• ?p=guitarra → Perfil Academia de Guitarra
• ?p=trabajo → Perfil Profesional & Código
• ?p=personal → Perfil Personal & Blog
• (sin parámetro) → Selector de Hub Principal

Sin backend ni base de datos. Lista para ser alojada en GitHub Pages o cualquier servidor de archivos estáticos.
